# Metabase Dash & Chatbot
My experience with the chatbot was quite pleasant. It wasn't really challenging but it was interesting to see how one can script a chatbot with pre determined text bubbles that are clickable. My initial approach was that I would try to make it recognize a 'keyword' that the user would type out. That was too difficult but given more time im sure its possible. I also liked thre customization aspect of the website. I found the clicking and dragging, essentially coding visually to be a little repetitive but also having a very low skill ceiling as it is very easy to program visually as thats how I see things in my head I made a chatbot which would make the APU admissions automated and easier to handle. Now coming to the Metabase Dashboard, This was something I was familiar with having worked with SQL before. I understood how the queries worked already, but I saw how the method of treating them like questions and then giving the user the option to frame it, made it more accesible. I had to do some fiddling to figure out how to get exactly what I wanted and I also had some trouble getting the map of India as one of the figures in the dash. But other than that these problems were solveable, simply had to give it some time. I think the over arching theme in both of these projects is that both of them aim to make the core "problem solving" more about problem solving rather that just learning syntax and memorizing code. Although these are important, It is more important that we know how to problem solve beforehand.
